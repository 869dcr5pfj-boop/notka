# Нотка — Android-проект

Приложение работает без интернета: страница лежит внутри APK (app/src/main/assets/index.html).

## Как получить APK

**Вариант А. Android Studio (на компьютере)**
1. Установите Android Studio (бесплатно).
2. File → Open → выберите эту папку. Дождитесь окончания синхронизации (нужен интернет).
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Во всплывающем окне нажмите «locate»: файл app-debug.apk лежит в app/build/outputs/apk/debug/.

**Вариант Б. Без установки программ (GitHub)**
1. Создайте бесплатный репозиторий на github.com и загрузите в него все файлы этой папки, включая скрытую папку .github.
2. Откройте вкладку Actions → Build APK → Run workflow.
3. Когда сборка закончится, скачайте архив notka-apk внизу страницы запуска. Внутри app-debug.apk.

## Как установить на телефон
1. Отправьте файл app-debug.apk ученикам (мессенджер, почта, облако).
2. На телефоне откройте файл. Android попросит разрешить установку из этого источника — разрешите.
3. Play Protect может показать предупреждение, потому что приложение не из Google Play. Нажмите «Всё равно установить».

## Google Play
Для публикации понадобятся: аккаунт разработчика, подпись релиза (Build → Generate Signed App Bundle) и более новый targetSdk (Google Play требует актуальный уровень API). Если обновите targetSdk до 35 и выше, проверьте отступы под строкой состояния.

## Изменения в приложении
Вся логика и дизайн — в одном файле app/src/main/assets/index.html.
